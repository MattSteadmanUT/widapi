## Lessons Learned

1. **Authorization at Multiple Layers**: API Gateway JWT validates first-line, Lambda applies policy second-line. Both must be correctly configured or users get 401.

2. **Parallel Task Error Handling**: One corrupted file in parallel download (SafeFetchWorkbookAsync) doesn't need to crash entire batch—wrap in try-catch at task level.

3. **Projections API Quirk**: The ProjectionsCentral API does NOT support SOC group filtering at the query parameter level; must query base endpoint and paginate through all results.

4. **Code Normalization Strategy**: Accept multiple formats on input (SOC "15-0000" or WID "150000"), normalize to WID format in database. This provides user flexibility without database schema changes.

5. **Dataset Naming for WID Audience**: Include WID 3.0 table names in display (e.g., "OEWS (IOWAGE)") to provide context to state agency users familiar with WID structure.
